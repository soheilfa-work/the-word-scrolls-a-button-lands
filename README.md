# The Word Scrolls. A Button Lands.

Thinkly is a one-page site where the word THINK is stacked in six layers. Scroll, and the layers fall back until the letter I drops, turns, and scrambles into **LETS DO IT**.

**Live demo:**
https://the-word-scrolls-a-button-lands.vercel.app/

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). A refresh always returns to the top, so the fall starts from the beginning.

## What’s on the page

- **Hero** — the intro, with floating idea cards
- **Spotlight** — the scroll trick (GSAP ScrollTrigger + Lenis)
- **Contact** — the note you can actually send

Built with Next.js, React, and Tailwind.
